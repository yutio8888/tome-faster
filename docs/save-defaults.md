# 0.2.12 默认配置

2026-09-14。库存归属压缩和 Fearscape 成功退出后的引用清理改为默认开启，base62 保持默认关闭。

| 选项 | 默认值 | 行为 |
| --- | --- | --- |
| `compact_inventory` | `true` | 原入包回调完成后，将符合条件的新物品归属 ID 改为原版支持的数字 |
| `fearscape_cleanup` | `true` | 原 Fearscape 退出成功、身份及状态检查通过后清除已结束的捕获引用 |
| `compact_save_names_base62` | `false` | 默认继续使用已有十进制短编号 |

省略配置即可使用这些默认值。也可以明确写出：

```lua
config.settings.faster_tome = {
    compact_inventory = true,
    fearscape_cleanup = true,
    compact_save_names_base62 = false,
}
```

修改配置后需要重启。已有的显式 `false` 保持有效，不会被新默认值覆盖；库存和 Fearscape
的非法非布尔值仍保守关闭。两项安装器继续检查原版方法身份及运行状态，显式关闭时
启动入口不会加载对应模块。没有增加保存时扫描或旧引用迁移，也没有改变原版读档器。

本版只调整默认开关及版本说明，事件实现与原有保护条件保持一致。
[独立测试](save-isolated.md)中的四个库存／Fearscape 保存场景通过各自的 CPU 门槛，
base62 未证明通过。该数据仍属于冻结的 0.2.11 单项比较，事件范围及置信区间保持原解释。

完整回归及受影响的三个套件在 JIT 关闭时均通过：保存／加载 101 项、库存 458 项
（28 个差分场景）、Fearscape 2,743 项（70 个场景）。短编号原生写入／原版读回
32,788 项仍通过。真实旧档完成 4 次保存和 4 次读回：显式关闭对照、三种默认场景、
三次无 Faster 原版读回及一次同包关闭选项后的原版读取器读回。默认场景省略全部三个
选项，确认库存与 Fearscape 生效，第 62 个名字仍为十进制 `62`。

无 Faster 测试保留官方 DLC 和诊断探针，仅调整副本的插件依赖声明；串行化归档不变。
67 个受保护文件和本体引擎源码复核未改动。详见
[验收记录](../evidence/faster-tome4-save-defaults-0.2.12/README.md)。
