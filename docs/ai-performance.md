# 0.2.9：寻路分配、遮罩组合与聊天缓存修复

2026-09-13，Faster ToME4 0.2.9。目标引擎为 ToME 1.7.6，固定 commit
`624a67329fe2ad440c5b344785a9c73fcf22ae63`。所有生产改动均在 addon 内，
没有修改引擎源码或加入原生库。FBO 回收保护继续默认开启，受击方向提示仍默认每 500 ms
最多一次。

本轮实现三项改进：降低 A* 搜索的临时分配和开放集合扫描成本；让遮罩批处理兼容
Faster 自身的 FBO 保护；修复聊天窗口重新排版后测量表意外变为强引用的问题。
真实地图的重复寻路测量显示 CPU 时间下降约 13–21%。这不是整局帧率或完整 AI 回合收益。

## A* 为什么能减少工作

原版 `Astar.calc` 每扩展一个节点，就扫描整个 `open` 选择最低评分，并重新建立邻格表及
多个坐标子表。`h_score` 表的值又只在写入后立即用于计算 `f_score`。

[FasterAI.lua](../overload/engine/FasterAI.lua) 在每次搜索内部做以下调整：

- 对已识别的方格邻接函数，从首次实际 `pairs` 顺序提取坐标偏移，并在本次搜索内复用。
  不跨搜索缓存路径，也不把新字段放入角色、地图或 Astar 实例。
- 删除多余的 `h_score` 表，以局部值计算评分。起点处原版的两次启发函数调用仍保留，
  因为自定义启发函数可能使用 RNG 或修改状态。
- `open` 达到 64 个节点时才建立带位置索引的辅助最小堆。原 `open` 表的插入、删除顺序
  保留；同分时仍选择 `next(open)` 最先返回的节点，堆不决定同分优先级。

堆处理评分升降；NaN 出现后继续原扫描，不重放回调。原哨兵值、地图/FOV 缓存查询、
已见条件、`add_check`、路径重建及移动 AI 保持原流程。大量同分时仍可能线性扫描。
每轮扩展检查邻格 helper、`pairs` 和六角模式；未知实现、六角格及特殊坐标调用原邻格函数。

安装器检查已验证的函数来源和行边界。未知的先前 Astar 覆盖保留并打印跳过原因；
[superload](../superload/engine/Astar.lua) 与 `ToME:load` hook 共同覆盖正常和提前加载两种路径。
这属于兼容检查，不是引擎文件的密码学验证；后来加载的其他 addon 仍可能覆盖方法。

## 真实地图结果

使用未经修改的 Linux 1.7.6 可执行文件，内嵌 LuaJIT 2.0.2；主机为 Ryzen 7 9800X3D，
Xvfb/llvmpipe。用同一份战斗准备存档新建三份独立 home；源存档和新副本均位于
`test-saves/`，每次测试的存档文件哈希前后相同。

在实际 50×50 地图、玩家 actor 和原生 FOV 路径缓存上，选取短、中、长各 8 条路径。
短路径为 2–3 步，中路径为 14–15 步，长路径为 51–63 步。选择规则由几何和原版路径长度
决定，不参考耗时。818 个可走目标全部可达，因此这一地图没有不可达测试样本。

原版 `calc` 直接从同一运行时原文件加载到独立环境；合用版本使用正常 addon 安装的实际
`Astar.calc`。另外测量仅邻格和仅堆分项；这些分项均包含删除 `h_score` 表的公共调整。
四种实现的完整路径逐一相同：24 条独立查询，三次加载合计 288 次比较，其中包括原版自检。

每个场景预热每种实现 30 批，再按原版 10 批校准，使每批目标约 25 ms。每种实现测量 8 批，
采用平衡拉丁方轮换顺序；GC 在计时期间开启，每批前完整收集。CPU 使用主线程
`CLOCK_THREAD_CPUTIME_ID`，另存单调时钟墙钟时间。下表先取每个会话 8 批均值的中位数，
再取三个会话中位数的中位数。

| 路径组 | 原版 CPU / 查询 | 0.2.9 默认合用 | CPU 减少 | 原版 / 合用 Lua 分配 |
| --- | ---: | ---: | ---: | ---: |
| 短 | 0.01025 ms | 0.00894 ms | 12.8% | 3.659 / 2.820 KiB |
| 中 | 0.06803 ms | 0.05442 ms | 20.0% | 20.698 / 8.865 KiB |
| 长 | 1.34297 ms | 1.05740 ms | 21.3% | 304.042 / 56.725 KiB |

分配是额外单独暂停 GC 后执行一批的 Lua 堆增量，再除以查询数，包含返回路径。
减少幅度约 23%、57%、81%；它不是操作系统 RSS，也不能直接推导 GC 最长停顿。
计时没有开启 builtin profiler、Lua debug hook 或 native preload。

这张地图上，主要收益来自邻格复用。仅邻格的长路径约 1.019 ms，合用约 1.057 ms；
堆分项没有显示额外收益。保留可独立关闭的堆，是因为下面的大开放集合样例表现不同。
三个会话的原版/合用长路径中位数分别为 1.327/1.072、1.344/1.054、1.343/1.057 ms。

运行结束时回合、角色位置、生命值、actor 数、暂停状态及正常安装的 Astar 方法均保持一致。
没有推动游戏回合，因此不能把这里的结果当成完整战斗 A/B。也未测量 Windows 或硬件 GPU。
[原始批次、会话摘要、源码哈希及协议](ai-game-results.json) 保留了全部正式测量数据；
独立预检不计入上述汇总。

## 遮罩批处理与 FBO 保护的组合缺陷

0.2.8 默认开启 FBO 保护后，`fbo:use()` 变成 Faster 的 Lua 包装。原遮罩批处理只认可原生 C
方法，因而遇到这个合法包装就回退，默认组合下优化失效。只分别测试两项无法覆盖这一问题。

[FBOGCGuard.lua](../overload/engine/FBOGCGuard.lua) 新增身份核对接口，识别自身仍有效的
metatable、index、标记、析构函数和 `use` 包装，并提供所包裹 C 方法的身份。
[FasterEffectMask.lua](../overload/engine/FasterEffectMask.lua) 仅据此确认兼容性；实际绘制
继续调用当前 `fbo:use()`，按正常时机排空回收队列。回收时序、默认开关和 shader 动画均未改动。
未知的第三方包装继续回退。

真实固定 native GL 夹具在同一进程组合两项，并测试两种加载顺序。修复前两组均在批处理
计数断言失败；修复后分别通过 889 项检查，六次绘制均进入批处理，缓存 1 次 miss、5 次 hit。
强制 GC 时的 framebuffer 绑定、像素及状态对照通过，第三方 wrapper 替换也验证回退。
真实地图寻路会话确认默认安装成功，但静止场景没有遮罩 draw；这里的绘制证据来自 native
夹具，不能声称该会话测出了渲染速度提升。

## 聊天测量表保留失效文本

聊天窗口原有 `line_size` 使用弱键，但 Faster 在字体/宽度变化时将其重置为普通表。
此后测量过的文本表被额外强引用，即使已从聊天记录删除，仍可能留到下次重排或关闭窗口。
[ShowChatLog.lua](../superload/mod/dialogs/ShowChatLog.lua) 现在重置为 `__mode='k'` 弱键表。
回归先触发宽度变化、测量文本、移除记录，再完整 GC，确认被丢弃的文本表可收集。

## 验证与复现

完整 `tests/run.sh` 已通过，包括保存/加载、角色导出、gzip、快捷栏、遮罩、FBO 生命周期、
保存回调、Cults 包装、同步快照刷新和 PNG 像素检查。新增组合与弱引用断言先在旧代码上失败，
再在修复后通过。详细日志见
[本轮回归证据](../evidence/faster-tome4-ai-0.2.9/README.md)。

A* 差分使用固定 `git show` 源码，比较路径、地图/启发值/检查/RNG 的有序调用轨迹及错误发生。
LuaJIT 开关两种模式共 1,243 组搜索、4,953 项检查；PUC Lua 5.1.5 另有 622 组搜索、2,494 项检查。
覆盖随机障碍、四/八方向、缓存开关、六角格、动态 helper、嵌套查询、NaN/无穷/有状态启发值，
以及原 `move_astar_advanced`、`move_astar`、`move_simple`、`aiFindSafeGrid` 调用链。
Lua 方法夹具仍使用明确的 native 桩，真实运行时证据与其分开报告。

```sh
bash tests/run.sh /path/to/engine-clone /path/to/dlc-fixtures
lua5.1 tests/test_ai.lua . /path/to/engine-clone
luajit tests/bench_ai.lua . /path/to/engine-clone 12 > ai-benchmark.csv
```

[真实游戏夹具](../tests/bench_ai_game/README.md) 是单独的测试 addon，只应装入隔离测试运行时。
它不会被正常 Faster 安装自动加载。玩家存档和 DLC 资产不进入公开证据。

如需单独关闭 A*，在引擎设置中加入并重启：

```lua
faster_tome = {ai_astar=false}
```

`ai_astar_heap=false` 或 `ai_astar_neighbors=false` 可分别关闭堆或邻格复用；
它们不会关闭公共的 `h_score` 表删除。全部字段省略时三项均启用。
